## 🚀 How to Deploy on GitHub Pages

1. Create a new GitHub repository (e.g. `gscs-bank`).
2. Upload all files from this directory to the repository:
   - `index.html`
   - `admin.html`
   - `css/`
   - `js/`
   - `assets/`
3. In your GitHub repository:
   - Go to **Settings** > **Pages**
   - Under **Build and deployment** > **Branch**, select `main` (or `master`) and `/ (root)` folder.
   - Click **Save**.
4. Your bank website is now LIVE at:
   `https://<your-username>.github.io/<repo-name>/`
   and the Admin Portal is at:
   `https://<your-username>.github.io/<repo-name>/admin.html`
